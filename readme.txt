ИНСТРУКЦИЯ ПО ПРИМЕНЕНИЮ
Заполнение столбца «Комментарий» из отчетов

НАЗНАЧЕНИЕ

Программа находит в книге Excel столбцы «Госномер» и «Комментарий», сопоставляет госномер каждой строки с названием папки ТС в источниках отчетов и заполняет соответствующий комментарий по статусам БК и ДУТ. Заголовки ищутся на листах независимо от регистра и расположения. Исходная книга по умолчанию сохраняется без изменений; результат создается в отдельном файле.

ЧТО ПОДГОТОВИТЬ

1. Книгу Excel формата .xlsx или .xlsm. В ней должны быть заголовки «Госномер» и «Комментарий» на одном листе. Если такие столбцы есть на нескольких листах, будут обработаны все эти листы.
2. Один или несколько источников отчетов. Поддерживаются:
   - папка «Отчеты», непосредственно содержащая папки с госномерами;
   - родительская папка, внутри которой находится папка «Отчеты»;
   - папка, непосредственно содержащая папки ТС с отчетами;
   - ZIP-архив с папкой «Отчеты», в которой расположены папки с госномерами. Архив читается без распаковки; прочие файлы, например data.txt, игнорируются.
3. В папке каждого ТС должен быть текстовый отчет .txt. Распознаются файлы «Отчет_*.txt» и файлы, имя которых совпадает с названием папки ТС (например, папка «B315ta98» и файл «B315ta98.txt»).

КАК РАБОТАЕТ ПРОГРАММА

- Значение «Госномер» сопоставляется с названием папки без учета регистра и небуквенно-цифровых символов.
- Если в папке ТС находится несколько распознанных отчетов, берется наиболее поздний по времени изменения.
- Если один госномер присутствует в нескольких источниках, используется отчет с наиболее поздним временем изменения. Для ZIP время берется из метаданных файла в архиве.
- По отчету формируется краткий статус: например, «Гео есть, ДУТ нет.» или «Гео НЕТ, ДУТ НЕТ.».
- Для геоданных учитывается статус «БК / Данные». Для ДУТ учитываются строки «Данные» в деталях датчиков; если их нет, применяется резервная проверка «ДУТ / Кол-во».
- Пустые или отсутствующие статусы трактуются как отсутствие данных. Содержимое раздела «ПРИМЕЧАНИЕ» не копируется.
- Если папка или распознаваемый отчет для госномера не найдены, строка Excel остается без изменений.

ЭЛЕМЕНТЫ ГЛАВНОГО ОКНА

1. «Источники отчетов (папки и ZIP-архивы)» — список всех добавленных папок и ZIP-архивов. Повторно добавленный источник не дублируется. Можно выделить несколько элементов и удалить их одновременно.
2. «Добавить папки...» — выбрать одну или несколько папок с отчетами. На macOS используется системный диалог множественного выбора. В Windows и Linux открывается диалог программы:
   - «Вверх» — перейти в родительскую папку;
   - поле пути и «Перейти» — открыть введенный путь;
   - список папок — выбрать одну или несколько папок клавишами Shift/Cmd/Ctrl; двойной щелчок открывает выбранную папку;
   - «Добавить выбранные» — добавить выделенные папки;
   - «Добавить текущую папку» — добавить открытую папку;
   - «Готово» — закрыть диалог.
3. «Добавить ZIP...» — выбрать один или несколько ZIP-архивов. Архив должен содержать папку «Отчеты» с папками ТС либо непосредственно папки ТС с распознаваемыми отчетами.
4. «Удалить выбранные» — удалить выделенные источники из списка программы. Исходные папки и архивы при этом не удаляются. Если ничего не выделено, программа покажет предупреждение.
5. «Файл Excel» — путь к исходной книге. Кнопка «Выбрать...» открывает диалог выбора .xlsx или .xlsm. Для .xlsm сохраняется поддержка VBA-макросов.
6. «Сохранить результат» — путь и имя выходной книги. Кнопка «Выбрать...» открывает диалог сохранения. По умолчанию после выбора книги предлагается имя рядом с ней с суффиксом «_с_комментариями»; расширение результата должно совпадать с расширением исходной книги.
7. «Не перезаписывать заполненные ячейки „Комментарий“» — если флажок установлен, непустые комментарии сохраняются, программа заполняет только пустые ячейки. По умолчанию флажок выключен, поэтому найденные значения комментариев заменяются результатом по отчету.
8. «Перезаписать исходный файл (сохранить под исходным именем)» — включает сохранение результата поверх выбранной исходной книги. Поле пути результата и кнопка выбора отключаются, выходным путем становится исходный файл. При снятии флажка снова используется отдельный выходной файл. Перед перезаписью рекомендуется сделать резервную копию книги.
9. Поясняющий текст — кратко напоминает, какие поля Excel используются и как формируется комментарий.
10. «Заполнить комментарии» — начать проверку источников и обработку книги. До запуска должны быть добавлены источники и выбран файл Excel. Во время выполнения не перемещайте и не переименовывайте файлы источников и книгу.

ПОРЯДОК РАБОТЫ

1. Запустите main.py либо Comments_from_reports.exe.
2. Нажмите «Добавить папки...» и/или «Добавить ZIP...». Можно использовать несколько источников разных типов.
3. Проверьте список источников. Чтобы убрать источник, выделите его и нажмите «Удалить выбранные».
4. В строке «Файл Excel» нажмите «Выбрать...» и укажите исходную книгу.
5. Проверьте путь в строке «Сохранить результат». При необходимости выберите другое имя и расположение.
6. При необходимости включите сохранение уже заполненных комментариев. Если нужно обновить исходный файл на месте, включите соответствующий флажок перезаписи; заранее сохраните резервную копию.
7. Нажмите «Заполнить комментарии».
8. После сообщения «Готово» проверьте выходную книгу и созданную рядом с ней выписку.

РЕЗУЛЬТАТ И ВЫПИСКА

После успешной обработки программа показывает количество просмотренных папок ТС и папок с распознанными отчетами, дублирующиеся и уникальные госномера, госномера без соответствия в Excel, число найденных строк и записанных комментариев, число пропусков из-за объединенных ячеек и сохраненных существующих комментариев, количество обработанных листов, а также пути сохраненной книги и выписки.

Выписка «*_выписка.xlsx» создается рядом с результатом и содержит листы:
- «Распознанные отчеты» — найденные госномера, папки, файлы и сформированные комментарии;
- «Отсутствуют в Excel» — найденные отчеты, госномеров которых нет в книге;
- «Дубли папок» — госномера, для которых отчеты найдены в нескольких папках-источниках;
- «Объединенные ячейки» — строки, где нельзя записать комментарий из-за объединения ячеек;
- «Существующие комментарии» — сохраненные непустые значения, если включена соответствующая настройка.

ОШИБКИ И ПРОВЕРКИ

- «Добавьте папку с отчетами и выберите файл Excel» — добавьте хотя бы один источник и укажите книгу.
- Сообщение о неподходящих источниках — проверьте, что в выбранной папке есть «Отчеты» или папки ТС с файлами .txt подходящего имени. Для ZIP проверьте структуру архива.
- «Не найдены текстовые отчеты» — в распознанных папках нет файлов, соответствующих правилам имени отчета.
- Ошибка о заголовках книги — проверьте наличие столбцов «Госномер» и «Комментарий» на одном листе.
- Если файл не удается сохранить, закройте его в Excel или выберите доступную для записи папку и повторите обработку.

ЗАПУСК И СБОРКА

Для запуска из исходного кода установите зависимости командой «python -m pip install -r requirements.txt», затем запустите «python main.py».

Для сборки приложения установите «python -m pip install -r requirements-build.txt» и выполните «python build.py». Результат появится в папке dist. PyInstaller создает сборку для текущей операционной системы: Windows-сборку .exe нужно собирать в Windows, macOS-приложение — в macOS. На компьютере пользователя для запуска собранного приложения Python устанавливать не требуется.
